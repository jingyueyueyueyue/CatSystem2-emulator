- 报告：`reports/emote_60fps_review_20261123.md`。
- 关键结论：
  - `7cfea05` 的关键帧索引、扫描线缓存、GPU 过渡端点均已实现但**默认关闭**；索引按 `CpuPlayer` 构造、在主线程建，启用会把成本搬到首次 906。

  - 首次登场：CA01 被 96 MiB 预算（展开 PSB + 对象树重复计入）与 8 MiB packed 门槛排除；2 MiB/帧 staging 无首姿态优先序，按需上传无界。
  - 过渡/染色：端点默认仍 `render_strict`；染色节点 `tint_surface` 触发设备帧回读 + 整帧复制，每角色每帧约 4–8 ms。
  - GPU 侧：35.5 draw → 24.5 batch/姿态；`clear_buffer` 清两倍、每帧建绑定组、每次 blend 整画布拷贝。
